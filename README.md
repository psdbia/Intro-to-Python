# Introduction to Python for Business Statistics

A practical, applied introduction to Python for students and professionals working with business data.  
This handbook integrates core Python programming concepts with essential statistical thinking, emphasizing exploratory data analysis (EDA) and real‑world decision‑making.

---

## Overview

This repository contains the full text of **_Introduction to Python for Business Statistics_**, a six‑chapter instructional handbook designed for learners who want to analyze data effectively without a computer science or advanced mathematics background.

The material is structured to build programming and statistical skills together, introducing each concept only when it becomes useful for answering a real analytical question.

Topics include:
- Python fundamentals for data analysis
- Measurement scales and data types
- Lists, NumPy arrays, and Pandas DataFrames
- Central tendency and variability
- Data cleaning and data quality
- Visualisation with Matplotlib and Seaborn
- Grouped analysis, pivot tables, and EDA workflows

The emphasis throughout is on **interpretation, judgment, and communication**, not just computation.

---

## Intended Audience

This material is suitable for:
- Business analytics and BI students
- Applied statistics or data fundamentals courses
- Analysts transitioning from Excel to Python
- Professionals seeking practical data analysis skills
- Instructors looking for a modular, open teaching resource

No prior experience with Python is assumed.

---

## Structure

The handbook is organized into six sequential chapters:

1. **Data, Variables, and Types**
2. **Lists, Arrays, and Central Tendency**
3. **Conditionals, Loops, and Frequency Distributions**
4. **Functions, Error Handling, and an Introduction to Pandas**
5. **Data Cleaning and Visualisation**
6. **Grouped Analysis, Pivot Tables, and the EDA Workflow**

Each chapter includes:
- Clear explanations in plain language
- Fully worked Python examples
- Business‑motivated scenarios
- Chapter summaries
- Review questions
